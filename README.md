# 数据中心设备台账系统

小团队用的数据中心设备台账管理，支持多用户权限。

**技术栈**：FastAPI + SQLite（后端）/ Vue3 + Element Plus + ECharts（前端）

## 快速启动

```bash
./start.sh
```

然后浏览器访问 **http://localhost:5173**

- 默认管理员账号：`admin` / `admin123`（**登录后请立即在右上角"修改密码"中改掉**）
- 停止服务：`./stop.sh`
- 首次运行 start.sh 会自动创建 Python 虚拟环境并安装依赖

## 功能

| 模块 | 说明 |
|---|---|
| 统计看板 | 设备总数、状态分布饼图、各机房设备数柱状图、30 天内过保提醒 |
| 设备台账 | 增删改查、多条件搜索筛选分页、Excel 导入/导出、单台设备变更历史 |
| 机房机柜 | 机房和机柜管理（有设备的机柜/机房不可删除） |
| 变更记录 | 所有新增/编辑/删除/导入操作自动留痕（谁、何时、改了什么） |
| 用户管理 | 仅管理员可见：创建用户、分配角色、重置密码、禁用账号 |

## Excel 导入说明

设备台账页 → 导入 → 下载模板 → 填好后上传：

- 按**资产编号**去重：已存在则更新该行，不存在则新增
- 机房不存在会自动创建；机柜需先在"机房机柜"页建好，找不到则留空
- 必填：资产编号、设备名称、类型（服务器/交换机/存储/防火墙/其他）
- 状态：在用/备用/维修/报废/退役（默认"在用"）
- 日期格式：`2026-01-15`
- 导入后显示成功/失败行报告，失败行不会影响其他行

## 目录结构

```
dc-inventory/
├── start.sh / stop.sh        # 启停脚本
├── backend/
│   ├── app/
│   │   ├── main.py           # 入口（自动建库、创建默认 admin）
│   │   ├── models.py         # 数据表：用户/机房/机柜/设备/变更日志
│   │   ├── auth.py           # JWT 认证与角色权限
│   │   └── routers/          # users / rooms / equipment / changes / stats / excel
│   ├── requirements.txt
│   └── dc_inventory.db       # SQLite 数据库（首次启动自动生成）
└── frontend/
    └── src/views/            # 登录/看板/设备/机房机柜/变更/用户页面
```

## 数据备份

数据全部存在单文件 `backend/dc_inventory.db`，定期复制该文件即可备份。

## 开发调试

```bash
# 后端（端口 8000，API 文档 http://127.0.0.1:8000/docs）
cd backend && .venv/bin/python -m uvicorn app.main:app --reload

# 前端（端口 5173，已配置代理到 8000）
cd frontend && npm run dev
```
